Как запустить Whisper локально

Превращаем аудио и видео в текст на вашем компьютере — бесплатно, без интернета, без отправки данных в облако

Что такое Whisper и зачем он вам

Whisper — это нейросеть от OpenAI (создатели ChatGPT), которая превращает речь в текст. Она понимает 99 языков, включая русский, украинский, английский.

Вы можете надиктовать заметку, расшифровать запись совещания, перевести интервью в текст — и всё это на своём компьютере. Бесплатно. Безлимитно. Конфиденциально.

Почему это удобно для руководителя:
  • Надиктовать письмо или поручение — вместо того чтобы печатать
  • Расшифровать встречу за минуту вместо часа стенографирования
  • Не отправлять записи совещаний в чужие облачные сервисы
  • Сэкономить на подписках — Whisper полностью бесплатный

Выберите свой путь

Есть два способа запустить Whisper. Для руководителя без технического опыта мы рекомендуем Способ 1 — готовые приложения.

Ваш сценарий Рекомендуемый способ Сложность
Хочу расшифровать файл прямо сейчас Способ 1 — готовые приложения Просто
Хочу диктовать текст в любую программу Способ 1 — приложения с диктовкой Просто
Хочу разобраться и использовать бесплатно без ограничений Способ 2 — командная строка Средне

Способ 1. Готовые приложения (никаких команд)

Самый простой вариант. Установили — открыли — работает. Всё происходит на вашем компьютере, данные никуда не уходят.

На Mac

MacWhisper — самое популярное приложение.
Цена: бесплатно (базовые модели) или 64 EUR (Pro, один раз на всю жизнь).

Как пользоваться:

  1. Скачайте с macwhisper.com
  2. Откройте приложение, нажмите Download model (скачайте модель, одну из списка)
  3. Перетащите аудиофайл в окно — через несколько секунд текст готов
  4. Можно также вставить ссылку на YouTube

На Mac App Store — под названием Whisper Transcription.

Whisper Notes — ещё один вариант, работает полностью офлайн.
Цена: $7.99 (iPhone) / бесплатный триал на Mac.

Поддерживает голосовую диктовку через клавишу Fn.

На Windows

StarWhisper — готовое приложение с установщиком.
Скачивайте из Microsoft Store или с starwhisper.ai.

Не требует Python и командной строки. Установили — работает.

WhisperDesktop — совсем простой вариант.
Загрузите ZIP-архив с GitHub Const-me/Whisper, распакуйте, запустите .exe.

  1. Скачайте WhisperDesktop.zip из раздела Releases
  2. Распакуйте в любую папку
  3. Запустите WhisperDesktop.exe
  4. При первом запуске выберите модель (рекомендуем ggml-medium.bin, ~1.4 ГБ)
  5. Загрузите аудиофайл — через минуту получите текст

WhisperUI — в Microsoft Store, красивый интерфейс.

Если нужна диктовка в любые программы

Чтобы не просто расшифровывать файлы, а диктовать текст в Email, Word, мессенджеры:

  • OpenWhispr (Windows, Mac, Linux) — openwhispr.com/ru/download. Бесплатно, с открытым кодом, работает полностью офлайн. Нажмите горячую клавишу, говорите — текст появляется где стоит курсор.
  • Spokenly (Mac, Windows, Linux, iPhone) — spokenly.app/ru. Локальные модели бесплатно без ограничений. 100+ языков, включая русский.
  • Wispr Flow (Mac, Windows, iOS, Android) — облачная диктовка с ИИ-очисткой. $15/мес. Работает в любом приложении.

Способ 2. Через командную строку

Если хотите максимальную гибкость — установите Whisper напрямую. Потребуется один раз выполнить несколько простых шагов.

Обратите внимание: этот способ требует установки нескольких программ и пары команд в терминале. Если не хотите возиться — используйте готовое приложение из Способа 1.
1
Установите Python

Скачайте Python с python.org (версия 3.10 или 3.11). При установке обязательно поставьте галочку Add Python to PATH.

2
Установите FFmpeg

Эта программа нужна, чтобы Whisper понимал аудиофайлы.

Windows: Скачайте ffmpeg-master-latest-win64-gpl.zip, распакуйте папку bin в C:\FFmpeg, добавьте C:\FFmpeg в переменную PATH.

Mac: Откройте Терминал и введите: brew install ffmpeg

3
Установите Whisper

Откройте командную строку (Win+R и cmd) или Терминал на Mac и введите:

pip install -U openai-whisper

Система сама скачает и установит Whisper. Это займёт около минуты.

4
Запустите транскрибацию

Перейдите в папку с вашим аудиофайлом и введите:

whisper zapis.mp3 --model base --language Russian

Whisper обработает файл и сохранит расшифровку в трёх форматах: .txt (текст), .srt (субтитры), .vtt.

Как выбрать модель Whisper

Чем больше модель — тем выше точность, но тем больше памяти требуется:

Модель Память Качество Для кого
tiny ~1 ГБ Среднее Попробовать в первый раз
base ~1 ГБ Хорошее Тесты и короткие записи
small ~2 ГБ Очень хорошее Повседневные задачи
medium ~5 ГБ Отличное Важные записи, интервью
large-v3 ~10 ГБ Максимальное Самые ответственные задачи
turbo ~6 ГБ Почти как large Лучший баланс скорости и качества

Совет: Начните с base или turbo — этого хватит для большинства задач.

Типичные проблемы

pip install не работает — попробуйте:

python -m pip install -U openai-whisper. Если не помогло — переустановите Python, убедитесь что стоит галочка Add Python to PATH.

ffmpeg is not recognized — FFmpeg не установлен:

На Windows: скачайте ffmpeg, распакуйте в C:\FFmpeg, добавьте эту папку в системную переменную PATH.

Whisper работает медленно — используйте маленькую модель:

Попробуйте base, small или turbo. Если есть видеокарта NVIDIA — установите PyTorch с CUDA. На Mac с M-чипом всё работает быстро из коробки.

Много ошибок в расшифровке — используйте модель побольше:

Попробуйте medium или large-v3. Укажите язык через --language Russian. Если аудио шумное — готовые приложения (Способ 1) часто справляются лучше.

Команда whisper не найдена после установки:

Перезапустите командную строку. Проверьте, что папка Python Scripts добавлена в PATH.
