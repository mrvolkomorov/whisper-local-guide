Как запустить Whisper на своём компьютере

Вы скачали модель с Hugging Face (файлы .bin, .ggml) — теперь рассказываем, как ей воспользоваться. Только готовые программы с графическим интерфейсом, никакой командной строки.

Что у вас уже есть (ситуация)

Скорее всего, вы скачали одну из этих моделей с Hugging Face:

  • Whisper от OpenAI (файлы .bin — tiny, base, small, medium, large-v3, turbo)
  • Parakeet от NVIDIA (.bin)
  • Whisper.cpp модели в формате GGML / GGUF (.bin)
Хорошая новость: эти модели — готовый «движок» для распознавания речи. Вопрос только в том, в какой программе этот движок запустить. Ниже — все подходящие варианты, от самых простых до продвинутых.

Программы, которые работают с моделями Whisper

Все программы ниже не требуют командной строки. Установили — выбрали модель — получили текст.

🔵

MacWhisper

macOS Новичок

Самое популярное приложение для Mac. Красивый интерфейс: перетащили аудиофайл — получили текст.

Цена: бесплатно (базовые модели) / €64 Pro (один раз)

Как использовать свою модель: MacWhisper сам скачивает модели при первом запуске. Можно добавить свою — скопировать .bin в папку моделей (~/Library/Application Support/MacWhisper/Models).

macwhisper.com

🟢

Whisper Desktop

Windows Новичок

Самая простая программа для Windows. Скачали ZIP, распаковали, запустили .exe — и всё.

Цена: бесплатно

Как использовать свою модель: При первом запуске программа предлагает скачать модель. Если у вас уже есть файл .bin с Hugging Face — положите его в папку models рядом с WhisperDesktop.exe и выберите его в меню.

GitHub Const-me/Whisper

Buzz

WindowsmacOSLinux Новичок

Кроссплатформенная программа с открытым кодом. Перетащили файл, выбрали модель — транскрибация готова. Поддерживает Whisper, Whisper.cpp.

Цена: бесплатно

Как использовать свою модель: В настройках можно указать путь к вашей модели .bin. Buzz сам подхватит файл.

GitHub chidiwilliams/buzz

Готовое приложение в Microsoft Store. Красивый интерфейс, поддержка субтитров, экспорт в разные форматы.

Цена: бесплатно / Pro

Как использовать свою модель: WhisperUI сам управляет моделями через встроенный менеджер. Можно импортировать свою.

Цена: бесплатно

Как использовать свою модель: Укажите путь к GGML-модели через интерфейс. Программа принимает любые .bin-файлы.

А если у меня модель с Hugging Face? Что делать с файлом .bin?

Ситуация: вы скачали с Hugging Face файл вроде ggml-medium.bin (или large-v3.bin, turbo.bin) — и не знаете, куда его теперь пристроить.

Вариант 1. Приложение, которое само возьмёт ваш файл

Откройте Buzz или WhisperDesktop. В настройках / при первом запуске укажите путь к вашему .bin-файлу. Программа подхватит модель и начнёт распознавать речь.

Вариант 2. Скопировать в папку приложения

У MacWhisper папка для моделей: ~/Library/Application Support/MacWhisper/Models/ — скопируйте туда ваш .bin.

У WhisperDesktop папка models/ рядом с программой.

У Buzz можно указать путь в настройках (Settings → Models → Add custom model).

Вариант 3. Купить приложение, которое всё делает само

MacWhisper (Mac), WhisperUI (Windows), SnailText (Mac + Windows) сами скачивают и настраивают модель. Просто нажмите кнопку «Download model».

Совет: Начинайте с turbo — он почти такой же точный, как large-v3, но в 8 раз быстрее. Если на ноутбуке мало памяти — берите small.

Итого: что делать прямо сейчас

  • На Mac: скачайте MacWhisper (бесплатно) или SnailText
  • На Windows: скачайте WhisperDesktop (бесплатно) или WhisperUI
  • Для диктовки голосом: OpenWhispr (бесплатно) или Wispr Flow
  • Российские сервисы (без VPN): Speech2Text, GuruScribe
